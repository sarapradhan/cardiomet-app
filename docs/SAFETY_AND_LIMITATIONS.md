# CardioMet Lens — Safety and Limitations

## What This Tool Is
Educational benchmarking for cardiometabolic biomarker context.

## What This Tool Is Not
Not diagnostic · not treatment advice · not a substitute for clinical judgment ·
not an emergency tool (call 911) · not a medical device (not FDA-cleared).

## Data Limitations
NHANES aggregates South, East, and Southeast Asians under "Non-Hispanic Asian" (RIDRETH3 == 6).
This tool cannot produce empirically validated South Asian-specific distributions from NHANES.
South Asian context is a guideline-backed risk-enhancing layer, not an empirical cohort.

Fasting glucose is a morning-session subsample — high missingness is expected and normal.
No patient biomarker value is imputed. Missing values are flagged in output.
Patients on medications may have values that do not reflect untreated baseline.
South Asian BMI thresholds (>=23/>=27.5) are discussion context only.
